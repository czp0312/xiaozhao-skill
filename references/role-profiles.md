# 岗位族能力画像

按岗位族汇总真实 JD 中反复出现的硬性要求、加分项和转岗切入点。用于 JD 分析、岗位匹配和投递排序时快速对照。

## 使用规则

- 本文件的画像来自 `2026-10-15` 前抓取的一批真实校招 JD（见文末样本清单），是**归纳结果**，不是任何一家公司的官方标准。
- 画像是"常见要求"，不是"录取门槛"。具体岗位以当次 JD 为准；与画像冲突时以 JD 为准。
- 学历、专业、毕业年份属于硬性要求，必须回到 JD 原文确认，不能用画像替代。
- 标注为"推断"的内容是经验归纳，不能在简历或面试中当作 JD 明示要求引用。

## 通用硬门槛

以下要求在校招技术岗中反复出现，可优先排查：

- 毕业年份：几乎全部岗位限定具体毕业区间（如 2027 届常见为 `2026-09` 至 `2027-12` 毕业）。
- 学历：算法研究类岗位普遍要求硕士及以上，部分要求博士；工程实现类岗位多数接受本科。
- 专业：算法类偏 计算机 / 人工智能 / 自动化 / 机器人 / 控制 / 电子信息；硬件类偏 电子 / 电气 / 机械电子 / 自动化；机械类岗位偏 机械 / 机电一体化。
- 实习时长：日常实习普遍要求"不少于 3 个月、每周 3 天以上线下"。

## 具身智能相关岗位族

### embodied_ai（具身智能算法）

- 典型岗位名：具身智能算法工程师、VLA 算法工程师、具身操作算法工程师、具身强化学习工程师、机器人学习算法工程师。
- 学历专业：硕士及以上为主，少数本科；计算机 / 人工智能 / 自动化 / 机器人 / 控制 / 电子信息。
- 必备技能：
  - Python + PyTorch，理解 Transformer、扩散模型等主流架构；
  - 强化学习基础（MDP、Bellman 方程）与常用算法（PPO、SAC、GRPO）；
  - 模仿学习（行为克隆、Diffusion Policy、DeepMimic、AMP 等）；
  - 至少一种机器人仿真平台（Isaac Lab / Isaac Sim / MuJoCo）；
  - 机器人学基础：正逆运动学、雅可比、多刚体动力学，常用 Pinocchio 等库；
  - Sim2Real 闭环：域随机化、系统辨识、真机部署与调试。
- 常见加分项：VLA / 世界模型 / 多模态大模型经验；顶会论文；头部公司核心项目实习；源码级仿真器定制；端侧部署（ONNX / TensorRT）。
- 机械等工科转岗切入点：机器人学、动力学建模、机构与关节理解是真实优势；短板通常在 RL 理论、PyTorch 工程和仿真环境使用，需要用可复现的项目补齐。
- 来源样本：速腾聚创具身强化学习工程师、纽鼐机器人具身智能算法工程师、银河通用 2027 具身领航者计划、星猿哲具身智能算法工程师、松霖机器人 VLA 操控算法工程师。

### motion_control（运控 / 运动控制）

- 典型岗位名：运动控制工程师、运控算法工程师、规划控制算法工程师、伺服 / 电机控制工程师。
- 学历专业：本科到硕士都有；自动化 / 控制工程 / 机器人 / 机电一体化 / 机械电子 / 电气。
- 必备技能：
  - 运动学与动力学建模、轨迹规划、位置 / 速度 / 加速度控制；
  - 控制基础：PID、前馈、阻抗 / 导纳控制、非线性控制、MPC、WBC、QP 求解；
  - C / C++ 与 MATLAB，Linux 使用能力；
  - 硬件调试：电机、舵机、驱动器、编码器、力矩传感器；
  - 总线协议：CAN / CANopen / EtherCAT / Modbus / PWM / 串口。
- 常见加分项：STM32 / DSP 实际开发经验；MuJoCo / Isaac 仿真；足式机器人平衡判据（ZMP、DCM、Capture Point）；ROS / ROS2。
- 机械等工科转岗切入点：机械、机电、控制专业直接对口；需要额外证明编程能力与算法实现，而非只做结构或装配。
- 来源样本：AnyWit 运动控制工程师、天控智能装备机器人应用工程师、新时达 2026 届运动控制工程师、松霖机器人规划控制算法工程师。

### computer_vision（计算机视觉）

- 典型岗位名：视觉算法工程师、视觉大模型算法工程师、感知融合算法工程师、SLAM 算法工程师。
- 学历专业：硕士及以上为主；计算机 / 人工智能 / 电子信息 / 自动化。
- 必备技能：深度学习与 CV 基础；Python + PyTorch；检测 / 分割 / 多模态融合；数据集构建与模型微调。
- 常见加分项：视觉大模型训练经验；端侧部署（ONNX / TensorRT）；ROS / ROS2 与 C++ 基础；顶会论文；机器人视觉项目。
- 机械等工科转岗切入点：机器人视觉、标定、传感器选型属于机电交叉，可结合硬件项目切入；纯 CV 算法岗对论文和模型训练经验要求较高。
- 来源样本：宇树科技视觉大模型算法工程师、松霖机器人感知融合算法工程师。

### embedded_software（嵌入式软件）

- 典型岗位名：嵌入式软件工程师、固件工程师、驱动工程师、BSP 工程师、MCU 开发工程师。
- 学历专业：本科为主，部分硕士；自动化 / 电气 / 电子信息 / 机电一体化 / 计算机。
- 必备技能：
  - C / C++，嵌入式 Linux 应用与驱动开发；
  - MCU 平台：STM32 / GD32 / ESP32 等至少一种；
  - 通信协议：UART / I2C / SPI / CAN / CANopen / EtherCAT / Modbus 至少两种；
  - 电机控制：BLDC / PMSM / 步进电机驱动、实时控制逻辑、丢步与抖动问题定位。
- 常见加分项：ROS / ROS2；Linux 驱动与设备树；RoboMaster / Robocon 等机器人竞赛；量产测试与软件文档能力。
- 机械等工科转岗切入点：机电一体化、自动化专业直接对口；机械专业需要用竞赛或实物项目证明 C 语言、MCU 和总线调试经验。
- 来源样本：因克斯智能嵌入式软件工程师（人形整机 / 关节电机）、松霖机器人嵌入式软件工程师（Linux）、宇树科技嵌入式软件工程师。

### embedded_hardware（嵌入式硬件）

- 典型岗位名：硬件工程师、嵌入式硬件开发、电路工程师、关节模组硬件工程师、高速信号硬件工程师。
- 学历专业：本科及以上；电子信息 / 电气 / 自动化 / 机电一体化。
- 必备技能：模拟与数字电路基础；原理图与 PCB 设计；电源与信号完整性；器件选型与 EMC 意识；示波器与焊接调试。
- 常见加分项：电机驱动板 / 关节模组设计；高速信号（PCIe、MIPI、DDR）经验；量产与可测试性设计。
- 机械等工科转岗切入点：机械专业需补电路基础与硬件调试，难度高于嵌软；机电一体化、电气专业更顺。
- 来源样本：因克斯智能硬件工程师（高速信号 / 关节模组）、AnyWit 嵌入式硬件开发。

### llm_app（大模型 / LLM 应用）

- 典型岗位名：大模型算法工程师、预训练 / 微调工程师、推理优化工程师、多模态大模型算法工程师。
- 学历专业：硕士及以上为主，部分博士；计算机 / 人工智能 / 数学 / 电子信息。
- 必备技能：Python + PyTorch；Transformer 架构与训练流程；分布式训练与显存优化；微调方法（SFT、LoRA、RLHF / DPO）；推理优化（量化、KV Cache、并行）。
- 常见加分项：顶会论文；大规模训练或线上服务经验；评测体系搭建；端侧 / 异构部署。
- 机械等工科转岗切入点：通常需要强算法背景，转岗难度高；若已有数学与编程基础，可从"大模型工程化 / 推理优化 / 数据工程"切入，而非纯预训练研究。
- 来源样本：具身方向中的世界模型、具身多模态大模型岗位与通用大模型岗位要求高度重合。

### agent_development（Agent 开发）

- 典型岗位名：Agent 研发工程师、智能体算法工程师、AI 应用工程师。
- 学历专业：本科及以上；计算机 / 软件工程 / 人工智能。
- 必备技能：Python；LLM 应用开发；工具调用 / 函数调用；RAG 与向量检索；Prompt 工程与评测；后端工程能力（接口、并发、异常处理）。
- 常见加分项：MCP、多智能体编排、任务规划；线上业务落地与成本控制；评估体系与数据闭环。
- 机械等工科转岗切入点：偏软件工程，转岗门槛低于大模型研究；机械背景若做过数据处理或自动化脚本，可从此方向切入。
- 来源样本：AnyWit Agent 研发工程师（实习）。

### ic_design（数字 IC / 验证 / FPGA）

- 典型岗位名：数字 IC 设计工程师、验证工程师、FPGA 工程师。
- 学历专业：硕士及以上为主；微电子 / 集成电路 / 电子信息。
- 必备技能：Verilog / SystemVerilog；数字电路与体系结构；UVM 验证方法学；时序与低功耗基础；脚本（Python / Tcl / Perl）。
- 常见加分项：流片或 FPGA 上板项目；EDA 工具链熟悉度；项目竞赛与专利。
- 机械等工科转岗切入点：专业跨度大，通常需要电子 / 微电子背景；机械专业不建议作为首选方向。

## 机械 / 自动化 / 电子专业的转岗优先级（推断）

以下排序是对上述 JD 归纳得出的经验判断，不是官方口径：

1. 机电一体化、自动化、控制类背景：`motion_control`、`embedded_software` 最顺，`embodied_ai` 需要补算法与仿真。
2. 机械设计背景：机器人机械结构、关节模组、灵巧手设计类岗位直接对口；转 `motion_control` 需补控制算法与 C++。
3. 电子信息、电气背景：`embedded_software`、`embedded_hardware`、`ic_design` 均可切入。
4. 所有工科背景：`agent_development` 是软件门槛最低的方向之一，但需要能证明编程与工程能力。
